# My Cookbook

My Cookbook is a modern personal recipe web application for collecting, organizing, and cooking
favorite recipes. It combines a calm, editorial cookbook experience with practical tools such as
ingredient search and nutrition tracking.

The current application is an early visual prototype. It demonstrates the design direction and
sample navigation, but it does not yet include persistent recipe storage, recipe detail pages, or
nutrition calculations.

## Technology

| Technology | Purpose |
|---|---|
| React | Frontend application |
| Vite | Development and build tooling |
| TypeScript | Type-safe application code |
| Tailwind CSS | Styling foundation |

## Run locally

1. Install Node.js 20 or newer.
2. Run `npm install`.
3. Run `npm run dev`.
